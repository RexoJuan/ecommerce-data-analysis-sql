# Análisis de E-commerce con SQL 🛒
Proyecto de análisis de datos para optimizar KPIs de ventas y comportamiento del cliente.

## + Objetivos de Negocio
- Identificar los productos con mayor rotación.
- Calcular el crecimiento de ventas Mes a Mes (MoM).
- Segmentar clientes según su gasto total.

## + Herramientas utilizadas
+ **Base de Datos:** ORACLE
+ **Editor:** Visual Studio Code
+ **Lenguaje:** SQL (CTEs, Window Functions, Joins)

## + Hallazgos Principales
- Ticket Promedio: El gasto medio por cliente es de $154.1.
- Categoría Líder: La categoría de belleza_y_salud representa el 9.26% de los ingresos totales.
- Geografía: El estado de SP (São Paulo) concentra la mayor cantidad de pedidos con 41746, sugiriendo una oportunidad de optimización logística ahí.

## + Análisis de Hallazgos y KPIs
A partir del análisis interactivo desarrollado en Power BI, se identificaron los siguientes puntos clave sobre la salud financiera y operativa del e-commerce:
1. Rendimiento de Ventas y Objetivos
- Brecha de Ingresos: A pesar de haber generado $13.59M en ventas totales, el indicador de cumplimiento muestra que estamos un 26.36% por debajo del objetivo establecido ($1.01M proyectado para el periodo actual vs $743K alcanzados).
- Ticket Promedio (AOV): El gasto medio por pedido se sitúa en $136.68. Este es un indicador crítico para estrategias de upselling y cross-selling.

2. Comportamiento Temporal y Estacionalidad
- Pico de Crecimiento: Se observa un crecimiento sostenido desde enero hasta mayo, alcanzando un máximo histórico de $1.50 millones.
- Punto de Inflexión: Existe una caída drástica en septiembre ($0.62M), seguida de una recuperación moderada en noviembre. Esto sugiere la necesidad de investigar factores externos (logística, cambios en algoritmos de pauta) o falta de campañas promocionales en el tercer trimestre.

3. Mix de Productos y Categorías
- Líderes de Mercado: Las categorías de Belleza y Salud y Relojes y Presentes son los motores principales del negocio, superando ambas el millón de dólares en ventas.
- Oportunidad de Expansión: Existe una "larga cola" de categorías con ventas bajas (Electrónicos, Pet Shop). Se recomienda analizar si el bajo volumen se debe a falta de stock o baja demanda para optimizar el inventario.

4. Perfil de Pago y Geografía
- Dominio de Crédito: El 78.3% de las transacciones se realizan mediante Tarjeta de Crédito, lo que indica un perfil de cliente que prefiere el financiamiento o cuotas.
- Concentración Geográfica: El mapa revela una alta densidad de ventas en el Sureste de Brasil (Sao Paulo, Río de Janeiro). Hay una oportunidad clara de expansión o mejora de costos de envío en las regiones del norte y centro.
